### Selected Projects

#### [grabogram](https://github.com/DennyBeus/grabogram) — Telegram data collection

A self-hosted Telegram channel parser controlled through a Telegram bot. Collect channel posts and export them as TXT or JSON directly into your chat, with proxy support.

**Built with:** Python · aiogram · kurigram · Docker

#### [voicetype](https://github.com/DennyBeus/voicetype) — Voice input for terminal agents

Dictate prompts in Russian mixed with English technical terms, review the transcript in an editor, and insert it into your terminal. Built for Linux / X11, with API-based transcription and optional text cleanup.

**Built with:** Python · Tkinter · PipeWire · OpenAI API

#### [school21](https://github.com/DennyBeus/school21) — Data Science & ML coursework

My Data Science projects at School 21: data processing, analysis, visualization and machine learning. Browse the [first DS bootcamp](https://github.com/DennyBeus/school21/tree/main/DS_Bootcamp_Part1), [second DS bootcamp](https://github.com/DennyBeus/school21/tree/main/DS_Bootcamp_Part2) and [ML introduction](https://github.com/DennyBeus/school21/tree/main/ML1_Introduction).
